FLASH PIXELBOY

Flashes the P4 app and stages the onboard ESP32-C6's WiFi co-processor firmware in one step - works entirely in this browser tab, nothing to install.

Hardware: an ESP32-P4X-EYE board (Espressif ESP32-P4 main chip, MIPI-CSI camera, LCD) with an onboard ESP32-C6-MINI-1U co-processor for WiFi, talking to the P4 over SDIO. This page flashes both.
Needs Chrome or Edge (WebSerial isn't supported in Firefox or Safari). Plug the board into its "Debug" USB-C port first.
Version:
Screen black? Press the Reset button on the front of the camera. The flash itself already succeeded (including the C6's WiFi firmware) - this is just the browser's reset signal occasionally not fully waking the board back up on its own.

On first boot the device detects the staged C6 firmware, flashes it over SDIO automatically, and restarts once on its own to boot into it (a brief screen blank there is expected, not a crash). After that it boots straight into the camera, and WIFI GALLERY works from the menu.

If flashing can't connect: hold the board's Boot button, press Reset, release Boot, then try again. If it still fails, use the esptool-based flash package instead - it's the most reliable path.
